使用说明

      
    

    


      

        把简历信息在这一页录一次，之后在任何招聘网站点一下书签，整页表单自动填好。
        全部在你自己浏览器里运行，不联网、不上传。
      


      
一、装书签（只做一次，用电脑）

      
    
        
  1. 把要用的信息填好。只填 8 个必填项就能生成可用书签，其余按网申要求补。
    2. 
        
  2. 点右侧「安装填表书签」——代码自动进剪贴板，并弹出三步引导。
    3. 
        
  3. 按 Ctrl + D，浏览器弹出「添加收藏夹」；名称随便写「填表」。
    4. 
        
  4. 按 Tab 跳到「网址」框 → Ctrl + A 删掉原有内容 → Ctrl + V → 回车。
    5. 
        
  5. 保存位置选「书签栏」，并按 Ctrl + Shift + B 让书签栏一直显示。
    6. 
      

      

        网页没法直接往你的书签里写东西（浏览器安全限制），所以复制之后要你亲自按这三下，一共只做一次。
        改完资料要重装：再点一次「安装填表书签」，把旧书签删掉再存新的，避免两条重名。
      


      
二、以后投简历

      
打开网申页面 → 点书签栏里的「简历填表」→ 表单自动填好，右下角弹出「已填 N 项，跳过 M 项」。

      
    
        
  • 只填空框：你手填过的内容不会被覆盖。
    • 
        
  • 多步骤表单：每翻一页点一次书签。
    • 
        
  • iframe 里的表单也能填（同域名）；跨域的会提示你点进框里再点一次。
    • 
      


      
三、常见问题

      

        
点了书签没反应

        

          先把页面按 F5 刷新一次再点；如果还是没动静，多半是这个网站把表单放进了
          iframe 里或做了特殊限制，换一份招聘网站的网申页面试试。
        


        
改完信息，书签还是旧的

        

          书签里存的是生成那一刻的数据快照。改完数据要重新下载书签文件，并且先删掉旧书签再导入，
          否则会有两条重名书签。
        


        
某些字段没填上

        

          每个招聘网站的字段叫法都不一样，常见写法（姓名、手机、毕业院校、入学时间…）基本都能认。
          遇到没认出来的，把那个输入框上方的文字连同网站名发给作者，就能补上匹配规则。
        


        
换电脑 / 换浏览器

        

          数据只保存在浏览器本地，换环境就读不到了。点顶栏「🔒 登录 GitHub 后下载」登录一次，
          按钮会变成「⬇ 下载表单助手到本地」，点一下能把整个工具连数据存成一个文件，换电脑直接打开。
          （下载必须先登录成功；如果你的网络打不开 GitHub，这一步会走不通。）
        


        
数据会丢吗

        

          只要不清浏览器缓存、不换设备就不会丢，但也没有云端备份兜底 ——
          清缓存、换电脑、用无痕窗口打开，都会读不到，而且找不回来。
          所以填到一半建议先「下载表单助手到本地」存一份，那个文件本身就是完整备份。
        


        
手机上能用吗

        
填写和预览可以，但手机浏览器装不了书签栏脚本，自动填表请用电脑。


        
数据安全吗

        

          所有内容只存在你这台电脑的浏览器本地存储里，页面不联网、不上传，断网也能用。
          但生成的书签文件里有你的身份证号、手机号，别外发。共用电脑用完点「清空全部」。
        


        
页面不上传，那作者怎么知道有人用

        

          只挂了一个轻量统计（Umami）记「打开了几次、从哪个网站点进来、什么浏览器」，不写 cookie、
          不采集你填的任何内容，也不追踪你在招聘网站上的操作。表单数据始终只留在你本机。
        

      


      
四、它填不了什么

      

        文件上传（简历 PDF、作品集）、短信验证码、需要点开浮层才能选的组件、以及带逻辑跳转的题目，
        这些仍然要手动完成。它省掉的是那几十个重复的文本框。
