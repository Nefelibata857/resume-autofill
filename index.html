使用说明

把简历信息在这一页录一次，之后在任何招聘网站点一下书签，整页表单自动填好。 全部在你自己浏览器里运行，不联网、不上传。

一、装书签（只做一次，用电脑）

  1. 在下面把要用的信息填好。只填 8 个必填项就能生成可用书签，其余按网申要求补。
  2. 点右上角「下载书签文件」，存下一个 简历填表书签.html。
  3. 浏览器按 Ctrl + Shift + O 打开书签管理器 → 右上角 ⋮ → 导入书签 → 选刚存的文件。
  4. 按 Ctrl + Shift + B 显示书签栏，导入的书签在「已导入」文件夹里，拖出来即可。

拖不进书签栏是正常的 —— 新版 Chrome 会拦下 javascript: 链接的拖拽。用上面的导入法就行。

二、以后投简历

打开网申页面 → 点书签栏里的「简历填表」→ 表单自动填好，右下角弹出「已填 N 项，跳过 M 项」。

  • 只填空框：你手填过的内容不会被覆盖。
  • 多步骤表单：每翻一页点一次书签。
  • iframe 里的表单也能填（同域名）；跨域的会提示你点进框里再点一次。

三、常见问题

点了书签没反应
有些网站的安全策略（CSP）会拦书签脚本。这时点右侧「复制填表脚本」，到网申页面按 F12 → Console → 粘贴 → 回车。Chrome 第一次会要求先输入 allow pasting 再粘贴。
改完信息，书签还是旧的
书签里存的是生成那一刻的数据快照。改完数据要重新下载书签文件，并且先删掉旧书签再导入， 否则会有两条重名书签。
某些字段没填上
点「下载诊断书签」，它只扫描不填写，会列出整页字段名和当前值，照着就能判断是哪个字段没认出来。
换电脑 / 换浏览器
点「导出 JSON」把数据带走，在新电脑「导入 JSON」，再重新生成书签。
手机上能用吗
填写和预览可以，但手机浏览器装不了书签栏脚本，自动填表请用电脑。
数据安全吗
所有内容只存在你这台电脑的浏览器本地存储里，页面不联网、不上传，断网也能用。 但生成的书签文件里有你的身份证号、手机号，别外发。共用电脑用完点「清空全部」。

四、它填不了什么

文件上传（简历 PDF、作品集）、短信验证码、需要点开浮层才能选的组件、以及带逻辑跳转的题目， 这些仍然要手动完成。它省掉的是那几十个重复的文本框。
